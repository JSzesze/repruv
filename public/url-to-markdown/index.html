How it works

  1. Paste a public HTTP or HTTPS URL.
  2. Repruv isolates the readable content and converts it to Markdown.
  3. Copy the result or download it as a .md file.

What remains

Headings, paragraphs, links, lists, quotes, and useful document structure remain. Navigation, advertising, and interface clutter are left behind.

Public by design

Repruv is for public pages. Results are cached and may be shared across requests, so private, authenticated, or expiring links should not be submitted.
